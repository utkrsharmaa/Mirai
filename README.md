# Mirai

Welcome to **Mirai**!
_This project is under development_

A manga reader app inspired by Tachiyomi and Houdoku, built with Rust for a smooth and fast UX. This monorepo contains the app (`app`) and its documentation site (`website`).

## Current Status
Early stages: basic UI in progress, no sources or reader yet.

## Upcoming Features
- Robust reader (single/double page, LTR/RTL, continuous scroll)
- Customization (themes, gaps)
- Offline reading
- Progress tracking (bookmarks, favorites)
- Personalized suggestions

## Ambitious goals
- Inbuilt OCR Translation

## Structure
- `app/`: Rust app for mirai
- `website/`: Next.js docs site

Personal project—not open to contributions yet. May change if interest grows.
